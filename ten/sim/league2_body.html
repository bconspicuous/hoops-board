산출방식 · v1 / v2

v1 · 기존 방식

  1. Basketball Reference 2021~2026 경기당 기록으로 선수별 가중 선형회귀(가중치 = 출전 경기 수), 2027 값 예측. 관측 범위의 75~125%로 제한.
  2. ESPN 2027 프로젝션과 역분산 가중으로 결합(2021~2025로 2026을 맞힌 백테스트 오차 기준). 신인 = NCAA 30% + ESPN 70%.
  3. 2027 실제 기록을 주차별 고정 비중으로 반영: 1~3주 10%, 4~6주 30%, 7~9주 50%, 10~12주 60%, 13~15주 70%, 16주~ 80%.

v2 · 시즌 초 회귀

  1. 학습: 2021~2026 각 시즌 Basketball Reference 경기 로그에서 개막 후 같은 일수(D일)까지의 경기당 기록 = 시즌 초 기록, 이후 잔여 경기당 기록 = 목표, 직전 시즌 경기당 기록 = 사전 기대치.
  2. 카테고리별·시즌 초 출전 수(1/2/3/4경기+)별 가중회귀: 잔여 기록 = b0 + b1×사전 기대치 + b2×시즌 초 기록(가중치 = 잔여 경기 수, 직전·잔여 각 20경기 이상).
  3. 적용: 사전 기대치 자리에 ESPN 2027 프로젝션, 시즌 초 기록 자리에 2027 실제 기록(ESPN API, 개막 후 D일). 시즌 초 출전이 없으면 사전 기대치만 쓰는 회귀.
  4. 실제 기록의 비중(b2)을 고정값 대신 과거 같은 시점의 데이터가 정함. 매주 D가 늘면 재적합.
